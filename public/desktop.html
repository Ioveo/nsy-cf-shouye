FAQ

常见问题解答

需要额外安装 .NET 运行库吗？

不需要。天才猫桌面 2.0 为完全自包含版本，所有依赖运行时均已编译内置，在纯净新电脑上双击即可秒启运行。

NovaDisk C盘搬家安全吗？

完全安全。采用 Windows 操作系统底层成熟的 NTFS Directory Junction 机制，文件实际存储在其他盘，系统原路径完全透明直通。

空间管家“搬到其他盘”会损坏软件或丢失数据吗？

绝对不会。采用 Windows 操作系统底层成熟透明的目录符号链接（NTFS Junction）技术，原本安装在 C 盘的软件与资料无损迁移到其他盘后，系统原路径依然直通可用，软件照常运行不丢数据。

支持双屏或多显示器吗？

完美支持。收纳盒可在任意显示器的左右贴边吸附，小组件支持自由拖拽跨屏放置，并能智能记忆每台显示器的布局参数。

## 2. 功能详析：智能收纳盒与抽屉式侧边吸附

### 2.1 创新体验：收纳盒“藏在屏幕侧边”
- **智能吸附边界**：用户只需按住收纳盒标题栏，将其拖曳至屏幕**左边缘、右边缘或顶部边缘**并松手，收纳盒将即时产生弹性物理动画，自动收进屏幕外边缘。
- **微光磨砂小把手**：隐藏后仅在屏幕边缘露出一道精致高颜值的磨砂亚克力把手（尺寸设计适中，如 `30px × 124px`），把手上清晰呈现该收纳盒的图标与名称（例如 `📁 文件夹 <`、`📁 AI <` 或顶部 `🌐 网站 ˅`）。
- **随用随出，零视觉负担**：鼠标轻触或点击把手，面板即如抽屉般平滑弹出；鼠标移开或点击面板上的收起按钮，立刻静默缩回边缘。
- **防重叠智能垂直避让**：当用户将多个收纳盒（如工作、娱乐、文档、AI 工具）同时收在同一侧时，算法会自动探测碰撞边界，将各个把手等距垂直排列，支持用户按住把手上下滑动重新排序，整洁有序。

### 2.2 真实图标渲染与无假数据机制
- **系统真实原生图标**：摒弃传统工具“假图标占位”的弊病，收纳盒一律动态读取并实时渲染文件、快捷方式（.lnk）、网址（.url）与可执行程序（.exe）的原始高清晰度真实图标与角标。
- **文件夹传送门（FolderPortal）**：支持直接将任意本地物理文件夹（如 `D:\工作项目` 或 `下载`）映射为桌面收纳盒，无需改变物理存放位置，即可在桌面上实时查看、拖入拖出与打开该目录下的所有文件。
- **自定义色彩与分类徽章**：按盒子名称自动匹配渐变圆角徽章（公文包、游戏手柄、调色盘、书本文夹等）与自定义玻璃浓度。

## 3. 功能详析：专业级截图翻译与离线 OCR 识别

### 3.1 微信级离线高精 OCR 引擎
- **本地神经网络驱动**：项目深度集成微信离线 OCR 核心组件（`WeChatOcr.dll` + `mmmojo_64.dll` + 离线权重模型），无需调用任何付费网络 API，不消耗用户流量，且**绝对保证个人隐私与敏感商业数据不上传云端**。
- **毫秒级精准解析**：支持中英文混排、手写字体、复杂排版排版识别，选区后毫秒级输出文本，并支持一键复制到剪贴板。

### 3.2 独创原图覆盖式翻译（ImageTranslatePainter）
- **原图就地视觉替换**：不仅能把翻译文字输出在侧边栏，更能通过智能背景色提取与排版适配，**直接在截图原图对应的文字区域上，覆盖渲染翻译后的文字**。
- **多语种互译**：支持中文、英语、日语、韩语等语言的高效互译，浏览外语文档、游戏画面、设计稿时一目了然。

### 3.3 强大辅助工具链
- **滚动长截图（LongScreenshotEngine）**：自动监测滚动视图（浏览器页面、长聊天记录、PDF 文档），自动向下滚动并进行像素级特征对齐拼接，一键生成无缝超长高清大图。
- **高保真轻量 GIF 录屏（ZenithGifEncoder + WuQuantizer）**：框选区域即可录制屏幕动画，内置 Wu 颜色量化算法，以极小的体积输出无杂色条纹的高清 GIF。
- **桌面置顶钉图（PinnedWindowForm）**：按快捷键截图后，一键固定在所有窗口最顶层，支持半透明度调整、滚轮缩放与位置随意摆放，边看参考边写代码/画图的必备利器。
- **智能表格结构识别（TableStructureDetector）**：自动分析截图中表格的横竖边框与单元格，一键导出规整的 CSV 或直接粘贴至 Excel 表格。
- **像素级放大镜与拾色器（MagnifierView）**：截图时自带精准像素取色器，提供 HEX / RGB 颜色代码一键复制。

## 4. 功能详析：快捷操作中心与全局热键中枢

### 4.1 全局热键架构（GeniusCatHotKeyManager）
- **Win32 底层低延迟捕获**：系统级全局热键注册，无论当前在运行全屏游戏、全屏看剧还是在大型 IDE 中写代码，均可随手一键触发响应。
- **自由组合与热键健康诊断（QuickKeyStatus）**：支持 Ctrl / Alt / Shift / Win 的任意组合键配置，内置智能自检机制，遇到与其他软件冲突或目标程序丢失时，主动标注提示并提供重映射方案。

### 4.2 核心快捷体验
- **Alt + 1 ~ 9 闪电直达槽位**：固定分配快捷槽位，绑定用户最高频使用的核心操作（如浏览器、微信、IDE、常用项目文件夹或自定义脚本）。
- **多类型目标灵活绑定**：
  - 应用程序与快捷方式（.exe, .lnk）
  - 常用文件夹目录
  - 网页网址（URL）
  - 浏览器多开独立分身 Profile 启动
  - 终端命令与脚本（PowerShell / CMD）
- **极速全盘检索（Everything64 集成）**：内置 Everything64 极速搜索引擎，按下 `Alt + Space` 全局呼出搜索框，毫秒级定位全盘数百万文件。
- **F1 极速截图 OCR**：按下 F1（或自定义快捷键）直接进入截图识字与翻译流水线。

## 5. 功能详析：NovaDisk 2.0 C盘空间管家

### 5.1 颠覆传统磁盘工具的现代美学
- **告别工控机老旧方块**：传统 WizTree / SpaceSniffer 采用 90 年代陈旧绿蓝红方块。NovaDisk 2.0 采用 **Fluent 2.0 Mica / Acrylic 现代磨砂流光质感** 与 **Smoothed Squarified 圆角磁贴 Treemap 树图**，自带呼吸光效和流体自适应动画。
- **硬件级 MFT 秒级全盘扫描**：通过 Win32 卷控制码直接解析 NTFS 文件系统主文件表（MFT），数秒内即完成对几百 GB 磁盘的完整空间解析。

### 5.2 独创“文件夹智能身份证”（知识库语义识别）
- 用户打开 C 盘最怕看到 `AppData\Local`、`ProgramData` 里莫名奇妙的英文文件夹。NovaDisk 内置规则知识库（`rules.json`），精准标注：
  1. **归属软件**：清晰显示这是哪款软件产生的（例如“微信电脑版数据”、“微信小程序缓存”、“VS Code 扩展缓存”、“iTunes 手机备份”）；
  2. **具体用途**：解释该目录存储的是核心配置、临时缓存还是离线媒体；
  3. **处置安全度**：权威告知“能不能删？删了会不会丢聊天记录？能不能搬走？”。

### 5.3 核心杀手锏：NTFS Junction 无损软链接搬迁机制
- **痛点**：普通用户最怕微信（`WeChat Files`）、QQ、iOS 备份、Docker 虚拟硬盘误删导致重要数据灰飞烟灭，但放在 C 盘又动辄占用 50~100GB。
- **解法**：NovaDisk 独创自动化 **NTFS Junction 无损置换搬家**：
  1. 自动化安全将超大目录迁移到 D 盘或外接盘；
  2. 在原 C 盘路径自动建立 Windows 原生透明符号链接（Reparse Point）；
  3. **微信、QQ 等软件在运行时完全无感知，照常读写，但 C 盘空间立刻瞬间释放数十 GB！**

### 5.4 Dism++ 级系统底层安全瘦身
- **休眠文件（hiberfil.sys）**：一键关闭或按需精简休眠体积，立刻节省与物理内存同等大小的空间（8G~32G）。
- **WinSxS 组件存储清理**：安全重置已废弃更新补丁。
- **系统临时文件与更新缓存一键清空**。

## 6. 功能详析：TopPeekDock 顶部窗口速览

### 6.1 悬停“偷看”窗口交互（Peek Preview）
- **屏幕正上方微光把手**：平时仅在屏幕顶部居中吸附一个微小的极简胶囊，上面用点阵标识当前固定的窗口数，完全不遮挡网页标签与窗口标题栏。
- **鼠标碰顶即展**：鼠标移到屏幕上沿，顶部 Dock 优雅展开，显示所有已加入速览的窗口图标和精简标题。
- **零干扰临时偷看**：鼠标悬停在某个窗口标签上片刻，**该后台窗口立即临时置顶显示，鼠标移开马上恢复原状**！在写文档时偷看参考数据、写代码时偷看预览网页极其顺手，不打乱原有窗口排布。

### 6.2 极速盲操与窗口管理
- **键盘高效盲操**：鼠标停在顶部栏时，键盘 `←` `→` 键可依次轮播偷看窗口，按下 `1 ~ 9` 数字键瞬间跳转，回车键激活置顶，Esc 键收回。
- **一键拖入固定**：按住任意正在运行的窗口拖曳至屏幕顶部栏松手，即可一键加入速览固定；点加号亦可直接从任务列表挑选。

## 7. 功能详析：桌面小组件系统（时钟/待办/纪念日）

桌面小组件挂载在 Windows 壁纸层，与桌面融为一体，采用高透明磨砂玻璃卡片设计（支持根据壁纸自动调节明暗与玻璃浓度），拖拽自由摆放：

### 7.1 天气时钟看板
- **高保真大号数字时钟**：包含时:分以及灵动跳动的小秒针（如 `21:21:40`）。
- **日期与农历日历**：显示星期、公历日期与传统农历（如农历八月廿八）。
- **实时天气与空气质量**：免密钥自动地理位置解析，展示室外气温、天气图标与空气健康指数。
- **喵喵开关**：右上角一键切换主页面板模式与灵动桌宠模式。

### 7.2 今日待办看板
- **清单化管理**：集中呈现今日待办、逾期提醒与已完成任务。
- **随手记录**：支持一句话自然语言解析（例如输入“明天下午三点开会”自动提取时间与提醒）。
- **微交互**：圆形小勾一键标记完成，带完成滑落动效。

### 7.3 纪念日与倒数日看板
- **精准倒计时胶囊**：以高对比度粉白胶囊呈现当前最近的纪念日（如“还有 1 天”、“0天 11:38:18”）。
- **循环与归档**：支持每年、每月或一次性纪念日与倒数日，清晰呈现重要日程。

### 7.4 一键整理桌面快捷胶囊
- 卡片醒目位置内嵌粉色流光快捷胶囊：**“⚡ 一键整理桌面 自动归类到收纳盒·可撤销 >”**，桌面杂乱时无需打开层层菜单，单击即刻恢复桌面清爽整洁。

## 8. 功能详析：治愈系桌宠灵动交互（GeniusPet）

- **完全本地化零依赖**：帧序列图片压缩内置在客户端内，无外部网络依赖，占用极少内存（通常不到 20MB）。
- **多动作物理交互**：
  - **呆萌常态**：坐在任务栏或壁纸角落眨眼、摇尾巴、打盹。
  - **拎起后颈**：鼠标按住小猫拖动时，小猫呈现被拎起后颈的生动挣扎/发呆状态。
  - **屏幕扒边**：将小猫拖到屏幕左侧、右侧或上边缘松手，小猫会灵巧地扒在屏幕边缘探头观察。
  - **半空掉落**：半空松手时，小猫将自动平滑落回任务栏或底部边缘。
- **功能快捷入口**：
  - **单击**：弹出暖心互动问候或最近一条待办提醒气泡。
  - **双击**：呼出快捷小卡片（一键桌面整理、25分钟番茄专注时钟、开始正向计时）。
  - **右键**：打开功能菜单或一键切回主页面板模式。

## 9. 功能详析：一键桌面智能整理与安全撤销

- **规则驱动智能分类（AutoJanitorEngine）**：
  - 自动识别可执行程序（.exe, .lnk）归入「应用/办公/游戏」；
  - 自动识别文档（.docx, .pdf, .xlsx, .pptx, .txt）归入「文档」；
  - 自动识别多媒体（.png, .jpg, .mp4, .mp3）归入「媒体」；
  - 自动识别压缩包与安装包归入「归档」。
- **桌面收件箱（DesktopInboxService）**：
  - 浏览器新下载的文件或临时丢在桌面的文件，先自动收纳进「今日新增」收件箱；
  - 第二天再自动归类，保护用户当前正在使用的临时文件不被误移。
- **久未使用沉淀（旧物箱）**：
  - 统计文件打开频率，超过 30 天未打开的文件自动归纳至「旧物收纳盒」，保持桌面始终处于轻盈状态。
- **完整撤销机制（TidyHistoryService）**：
  - 整理完毕后右下角弹出结果通知，如果整理不符合预期，**单击“一键撤销”即可全自动原路放回桌面原来的坐标位置**，零心理负担。

## 10. 技术架构、打包与部署特性

- **.NET 10 + 现代 WinForms/Win32 深度融合**：兼具极速启动、毫秒级响应与现代高颜值 DirectWrite/GDI+ 亚克力高保真排版。
- **彻底的自包含部署（Self-Contained win-x64）**：
  - 编译采用 `--self-contained true`，内置完整 CoreCLR 运行时环境。
  - **目标电脑无需安装 .NET SDK、无需安装 Desktop Runtime、无需安装 VC 运行库**。
- **商业级 Inno Setup 6 封装流水线**：
  - 125% DPI 现代抗锯齿高保真安装向导。
  - 支持普通用户权限免 UAC 极速安装，亦支持全系统管理员安装。
  - 智能进程守护：安装或更新前自动结束旧进程，避免文件锁定。
